
# Awesome Filament

A curated collection of useful links, plugins, packages, tutorials, and resources for **FilamentPHP** — the modern admin panel framework for Laravel.

## 🚀 What’s Inside

This list includes:

- 🔌 Filament plugins & extensions
- 📚 Tutorials & articles
- 🎥 Video guides and walkthroughs
- 🧾 Official documentation links
- 💡 Tips to build better Filament apps

## 📌 Categories

- **Plugins** – Useful add-ons to extend Filament
- **Admin UI** – Themes & UI helpers
- **RBAC Tools** – Role & permission resources
- **Tutorials** – Step-by-step guides
- **Community** – Videos, talks, and example projects

## 📎 Contributing

Contributions are welcome!  
If you know a resource that should be on this list:

1. Fork the repo  
2. Add your link under the relevant category  
3. Submit a Pull Request

## 🤝 Rules

- Provide a **clear title** for each resource
- Include a **short description**
- Group under the correct category

Example:
```markdown
- **Filament Shield** – Adds role & permission management to your Filament admin panel.
````
